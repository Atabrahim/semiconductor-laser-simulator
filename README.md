# Semiconductor Laser Simulator

GaAs/AlGaAs quantum-well laser modelling from confined states to optical gain,
threshold and carrier–photon dynamics.

**Development in progress. No validated device predictions or release yet.**

See [frozen V1 scope and recovery record](docs/PROJECT_PROGRESS.md).
The project adds active optoelectronics to the five completed portfolio projects.
Reference material parameters and assumed device inputs will be distinguished;
all calculations are model results, not experimental measurements.

Original code will be MIT licensed. Development is AI-assisted.
